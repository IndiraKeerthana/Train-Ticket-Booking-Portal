## 🚆 Train Ticket Booking Portal 


This project started as a way for me to understand how real-world booking systems are designed behind the scenes.

When we book a train ticket, a lot happens in the background, passenger details are stored, seat availability is updated, payments are recorded, and cancellations are handled correctly. I wanted to build the database that powers all of that.

Using MySQL, I designed a complete relational database for a Train Ticket Booking Portal. The project focuses on creating a clean schema, maintaining relationships between entities, and automating business logic using stored procedures and triggers.

---

## 🌟 What This Project Does

The database supports the core operations of a railway reservation system:

- Storing passenger information
- Managing trains and schedules
- Booking tickets
- Cancelling reservations
- Tracking payments
- Viewing booking history

## How to Run

1. Clone this repository.
2. Open MySQL Workbench.
3. Create a new schema.
4. Import `train_ticket_booking.sql`.
5. Execute the script.

Once imported, the database is ready to use.
